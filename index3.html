📘 สรุปแท็ก HTML กิจกรรม 1–5

1. แท็กหัวข้อ (Heading)

ใช้สำหรับแสดงหัวข้อ โดย <h1> ใหญ่ที่สุด

<h1>หัวข้อใหญ่</h1> <h2>หัวข้อรอง</h2> <h3>หัวข้อย่อย</h3>

2. แท็กข้อความ

ใช้แสดงข้อความทั่วไป และตกแต่งตัวอักษร

<p>นี่คือข้อความอธิบาย</p> <strong>ตัวหนา</strong> <i>ตัวเอียง</i> <u>ขีดเส้นใต้</u>

3. แท็กรูปภาพ (img)

ใช้แสดงรูปภาพ โดยนิยมใช้ External URL

<img src="URL" height="150" alt="คำอธิบายรูป">

3. แท็กลิงก์ (ตัวอย่าง)

ใช้เชื่อมไปยังเว็บไซต์อื่น

ไปที่ Google <a href="https://www.google.com" target="_blank">Google</a>

🔹 4. แท็กรายการ (List) — กิจกรรมที่ 3

Ordered List (ol) : รายการแบบมีลำดับเลข


<ol>
  <li>HTML</li>
  <li>CSS</li>
  <li>JavaScript</li>
</ol>

Unordered List (ul) : รายการแบบสัญลักษณ์จุด


<ul>
  <li>คอมพิวเตอร์</li>
  <li>อินเทอร์เน็ต</li>
  <li>สมุดจด</li>
</ul>

4. แท็กรายการ (ตัวอย่าง)

ol = รายการแบบมีตัวเลข

<ol> <li>HTML</li> <li>CSS</li> </ol>

ul = รายการแบบสัญลักษณ์

<ul> <li>คอมพิวเตอร์</li> <li>อินเทอร์เน็ต</li> </ul>

🔹 5. แท็กตาราง (Table) — กิจกรรมที่ 4

ใช้แสดงข้อมูลเป็นแถวและคอลัมน์

  • <table> = ตาราง
  • <tr> = แถว
  • <th> = หัวตาราง
  • <td> = ช่องข้อมูล

<table border="1">
  <tr>
    <th>ลำดับ</th>
    <th>ชื่อสินค้า</th>
    <th>ราคา</th>
  </tr>
  <tr>
    <td>1</td>
    <td>เลย์</td>
    <td>22 บาท</td>
  </tr>
</table>

👉 สามารถใช้ <thead>, <tbody>, <tfoot> เพื่อความเป็นระเบียบ

5. แท็กตาราง (ตัวอย่าง)

ใช้แสดงข้อมูลเป็นแถวและคอลัมน์

ลำดับ ชื่อสินค้า ราคา
1 เลย์ 22 บาท
<table> <tr> <th>ลำดับ</th> <th>ชื่อสินค้า</th> </tr> </table>

🔹 7. แท็กฟอร์ม (Form) — กิจกรรมที่ 5

ใช้รับข้อมูลจากผู้ใช้


<form>
  ชื่อ: <input type="text"><br>
  Email: <input type="email"><br>
  <input type="submit" value="ส่งข้อมูล">
</form>

ประเภท <input> ที่ใช้บ่อย

  • text – รับข้อความ
  • email – รับอีเมล
  • radio – เลือกได้ 1 ค่า
  • checkbox – เลือกได้หลายค่า
  • submit – ส่งข้อมูล
  • reset – ล้างข้อมูล

ตัวอย่าง radio


เพศ:
<input type="radio" name="g"> ชาย
<input type="radio" name="g"> หญิง

Textarea : พิมพ์ข้อความยาว


<textarea rows="4" cols="30"></textarea>

Select & Option : เลือกจากรายการ


<select>
  <option>มัธยมต้น</option>
  <option>มัธยมปลาย</option>
</select>
